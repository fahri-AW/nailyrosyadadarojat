# Portofolio Digital Naily Rosyada Darojat

Portofolio akademik dengan struktur HTML, CSS, dan JavaScript terpisah.

## Struktur
- `index.html`: markup dan metadata halaman.
- `css/styles.css`: styling, desain responsif, serta aksesibilitas.
- `js/main.js`: interaksi, render konten, modal, filter, formulir, dan admin UI.
- `assets/`: foto dan sertifikat.

## Menjalankan lokal
```bash
python -m http.server 8000
```
Buka http://localhost:8000.

CMS saat ini menyimpan data pada localStorage browser. Formulir kontak belum terhubung ke backend.
